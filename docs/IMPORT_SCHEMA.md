# Sharpr import schema

Sharpr contains no AI. Content is generated by external AI agents and imported as JSON (or CSV for flat content). This document is the contract.

## File shapes

Either a **bare array of content items**:

```json
[ { "type": "speaking_topic", "title": "...", "prompt": "..." } ]
```

or an **object** with any of these keys:

```json
{
  "content": [ ...content items... ],
  "vocabulary": [ ...vocabulary items... ],
  "resources": [ ...resources with "topics": ["<content title>"] ],
  "collections": [ { "name": "...", "description": "...", "items": ["<content title>", "tag:flutter"] } ],
  "books": [ ...books... ]
}
```

## Content item

Only `type`, `title` and `prompt` are required.

| field | type | notes |
|---|---|---|
| `type` | enum | `speaking_topic`, `interview_question`, `technical_topic`, `storytelling_prompt`, `podcast_topic`, `debate`, `scenario`, `book_prompt`, `knowledge_topic`, `quick_speaking` |
| `title` | string | short label shown in lists |
| `prompt` | string | the instruction the user speaks to |
| `category` | string | e.g. `System Design`, `Leadership`, `Economics` |
| `subcategory` | string | e.g. `state management` |
| `difficulty` | enum | `beginner`, `intermediate`, `advanced`, `expert` (default `intermediate`) |
| `duration` | number | recommended speaking minutes (or use `duration_seconds`) |
| `preparation_seconds` | number | default 30 |
| `tags` | string[] | free-form |
| `guiding_questions` | string[] | shown during prep |
| `track` | enum | interview only: `flutter`, `full_stack`, `ai_engineer`, `system_design`, `cto`, `founder`, `behavioral` |
| `model_answer_notes` | string | interview only: what a strong answer covers (revealed after speaking) |
| `framework` | enum | story only: `STAR`, `Situation → Conflict → Resolution`, `Beginning → Tension → Climax → Ending`, `Hook → Story → Lesson`, `Before → Change → After` |
| `audiences` | enum[] | tech talk: `beginner`, `junior developer`, `senior developer`, `CTO`, `CEO`, `investor`, `customer`, `no jargon` |
| `opening_question`, `discussion_points[]`, `follow_up_questions[]`, `controversial_angle`, `closing_question` | | podcast only |
| `position` | string | debate: the statement, e.g. "Microservices are overused." |
| `counterarguments` | `{against: "defend"\|"oppose", text}[]` | debate: revealed one at a time. `against: "defend"` attacks the defender. |
| `role`, `situation` | string | scenario only |
| `learning` | object | `{ short, detailed, key_points[], examples[], common_mistakes[], interview_questions[], related_topics[] }` revealed after speaking |
| `resources` | resource[] | inline resources attached to this item |

## Resource

```json
{ "type": "article", "title": "...", "url": "https://...", "author": "...", "description": "...", "body": "...", "tags": [] }
```
`type`: `article`, `documentation`, `video`, `podcast`, `book`, `course`, `notes`, `cheatsheet`, `website`.
Top-level resources add `"topics": ["<content title>", ...]` to link to many topics.

## Vocabulary

```json
{ "word": "leverage", "meaning": "...", "example": "...", "pronunciation": "...", "synonyms": [], "category": "executive language", "discovered_in": "...", "personal_example": "..." }
```
Categories: `professional phrase`, `precise vocabulary`, `concise expression`, `executive language`, `transition phrase`, `storytelling expression`, `persuasive language`, `technical term`, `idiom`, `other`.

## Book

```json
{ "title": "...", "author": "...", "status": "reading", "total_chapters": 12, "current_chapter": 3, "notes": "", "ideas": [], "quotes": [], "concepts": [], "vocabulary": [], "prompts": [] }
```

## CSV

Flat content only. Header row required. Columns match the content fields; array columns (`tags`, `guiding_questions`, `audiences`) are `|`-separated.

## Example prompt for an external agent

> Generate 50 senior Flutter interview questions as JSON matching the Sharpr import schema (bare array). Use `type: "interview_question"`, `track: "flutter"`, a `subcategory` from: Dart, Flutter internals, state management, architecture, performance, animations, platform channels, native integration, testing, deployment. Include `model_answer_notes` and 2–4 `guiding_questions` for each. Vary `difficulty` between `intermediate`, `advanced`, `expert`. Output only JSON.
